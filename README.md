# Voice Keyboard（内测）

说中文，发外文。一个 Mac 菜单栏小工具：在任何聊天框里按快捷键弹出浮窗，说中文或打字，Claude 实时翻成英文（也能翻成日语、韩语、西班牙语、法语、德语、意大利语），回车直接发出去。看不懂的外文，截个图就翻成中文。

微信、Slack、WhatsApp、邮件……任何 App 都能用。

目前是**邀请制内测**，需要邀请码才能使用，不需要自己的 API Key。

## 安装

1. 打开下载的 `Voice-Keyboard.dmg`，把 Voice Keyboard 拖进旁边的"应用程序"文件夹。
2. 第一次打开时，macOS 可能会提示"无法验证开发者"或"Apple 无法检查它是否包含恶意软件"。这是因为内测版还没有经过 Apple 公证，并不是病毒。这样打开：
   - 先点"完成"关掉提示；
   - 打开 **系统设置 → 隐私与安全性**，往下滚到"安全性"，找到关于 Voice Keyboard 的提示，点 **仍要打开**，再输入电脑密码确认。
3. 打开后会出现新手引导：
   - 输入邀请码；
   - 打开"辅助功能"权限（必需，用来把译文粘贴进聊天框并替你按回车）；
   - 麦克风（点浮窗里的麦克风说话）和屏幕录制（截图翻译）是可选的，用到时再开也行。

## 怎么用

1. 在聊天框里按快捷键（默认 `⌥ Space`）弹出浮窗。
2. 说话或打字：可以用微信等输入法的语音输入，也可以点浮窗中间的麦克风（或按 `⌘D`）。
3. 停顿约半秒，译文自动出现，同时复制到剪贴板。
4. 按 `↩` 把译文填进聊天框并发送；`⌘↩` 只填入不发送；`esc` 关闭。

| 按键 | 作用 |
|---|---|
| `⌘1`–`⌘7` | 切换目标语言：英、日、韩、西、法、德、意 |
| `Tab` | 切换语气：口语 ⇄ 正式 |
| `⌘S` | 截图翻译：框选屏幕上的外文，翻成中文 |
| `⌘R` | 朗读译文 |
| `⇧↩` | 换行 |

快捷键、默认语言、是否自动发送等，都可以在菜单栏图标 → 设置… 里改。

## 隐私

- 你输入的文字和录音只用于这一次翻译或识别，服务器**不保存任何内容**，只记录使用次数。
- 截图翻译在你的 Mac 上识别文字，图片不会上传。
- 受 Anthropic 和 OpenAI 的地区政策限制，中国大陆、香港、澳门暂时无法使用。

## 更新

App 每天会自动检查一次更新，也可以点菜单栏图标 → 检查更新…。有新版本时下载新的 dmg，把 Voice Keyboard 拖进"应用程序"替换旧版本即可，设置和邀请码都会保留。

更新后第一次打开如果弹出钥匙串窗口，输入电脑密码，点"始终允许"。
